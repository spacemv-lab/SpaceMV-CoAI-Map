# Repository Management

## 仓库流转

```text
开发仓库 -> 审计仓库 -> 开源仓库
```

## 当前仓库角色

- 当前仓库是内部开发源仓库
- 审计仓库和开源仓库由脚本对当前仓库做删减、替换、补充后生成

## 审计仓库

用途：

- 安全审计
- 管理层周报
- 对外发布前中间态

## 开源仓库

用途：

- 公开发布
- 社区协作

## 基本规则

- 内部仓库保留完整开发内容
- 审计仓库删除不应扩散的内部开发内容
- 开源仓库进一步移除内网地址、密钥、敏感部署配置和内部流程细节

## 周报要求

- 审计仓库保留 `reports/` 目录
- 周报至少包含：
  - 本周完成
  - 本周合并 PR
  - 下周计划
